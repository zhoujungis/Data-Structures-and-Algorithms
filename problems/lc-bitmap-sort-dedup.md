# 【海量数据】10 亿整数排序去重：一张位图，119 MiB 换 4 GB

**来源**: https://zhoujungis.github.io/article/lc-bitmap-sort-dedup/
**标签**: 算法、海量数据、面试

## 题目

10 亿个无序整数，内存有限（比如 1 GB），要求**排序去重**后输出。如果只问个数，就是**统计 distinct 个数**。追问：如果还想知道哪些数重复了、哪些只出现一次，怎么办？

```
输入: 10 亿个无序 int32（示例：值域 0 ~ 63 的 [37, 12, 37, 5, 63, 42]）
输出: 去重后升序序列（示例：5, 12, 37, 42, 63）
追问: 输出「出现过 / 重复了 / 只出现一次」三类数的集合
```

约束与假设：

- 整数为 32 位，值域有界（例如 `0 ~ 10^9 - 1`），可用内存约 1 GB；
- 10^9 个 int32 原样存放需 `10^9 × 4 = 4 GB`，`HashSet` 需几十 GB，均不可行；
- 负数需先按 `v - min` 平移成非负下标。

## 思路

- 核心是思维转换：**数据量决定要处理多少个输入，值域决定位图要开多大**。值域 10^9 只需 `10^9 bit ≈ 119 MiB`，压缩比 32 : 1，1 GB 内存轻松装下。
- **去重是白送的**：一个 bit 只能置 1 一次，重复的数再来那一位已经是 1，直接跳过 —— 没有比较、没有哈希。
- **排序也是白送的**：最后按 bit 下标从小到大扫一遍，输出天然有序。
- 位运算三件套：定位 `word = v >> 5`、`bit = v & 31`（`v = word × 32 + bit`），置位 `words[word] |= 1 << bit`，清位 `words[w] &= ~(1 << bit)` —— 置位写成 `=` 会冲掉整字，清位丢 `~` 会误伤同字其他位。
- 1-bit 位图答不了「出现几次」：出现过两次和一次 bit 都是 1。要区分「一次 / 多次」必须加一个 bit（2-bit 位图，`00 → 01 → 10`，`10` 是「多次」的垃圾桶），空间翻倍换次数分档。
- 前提是值域有界：值域远大于数据量时位图巨亏（手机号值域 `10^11` 要 11.6 GiB），64 位 / UUID 场景应转向范围分桶、哈希分区或外排。

## 答案

### 解法一：1-bit 位图（时间 O(n + 值域) / 空间 O(值域 / 8) 字节）

最小可用版本，去重 + 排序 + 判存一次解决，适用于只要「出现过哪些数 / distinct 个数」的场景。

```python
class BitMap:
    def __init__(self, size: int):
        self.size = size
        # 每 32 个整数挤进一个 32 位字
        self.words = [0] * ((size + 31) // 32)

    def add(self, v: int) -> None:
        # 置位：只翻 v 对应的那 1 bit，同字其他位原样不动
        self.words[v >> 5] |= 1 << (v & 31)

    def contains(self, v: int) -> bool:
        return (self.words[v >> 5] >> (v & 31)) & 1 == 1

    def sorted_distinct(self) -> list[int]:
        # 按 bit 下标从小到大扫，输出即有序去重序列
        return [v for v in range(self.size) if self.contains(v)]
```

### 解法二：2-bit 位图（时间 O(n + 值域) / 空间 O(值域 / 4) 字节）

`00` 未出现 → `01` 一次 → `10` 多次（`11` 为保留态、兜底视作多次）。适用于追问「哪些重复、哪些只出现一次」，一次扫描同时输出三个集合；空间是 1-bit 版的两倍。

```python
def add(self, v: int) -> None:
    cur = self._state(v)
    if cur == 0b00:
        self._set(v, 0b01)          # 一次
    elif cur == 0b01:
        self._set(v, 0b10)          # 升级成多次
    elif cur == 0b11:
        self._set(v, 0b10)          # 保留态兜底
    # cur == 0b10：已经是多次，什么都不做
```
