# 【LC 470】用 Rand7() 实现 Rand10()：拒绝采样 2.45 次

**来源**: https://zhoujungis.github.io/article/lc-470-implement-rand10-using-rand7/
**标签**: 算法、概率、随机化、LeetCode、面试

## 题目

已有函数 `rand7()`，它均匀随机地返回 `[1, 7]` 的整数。请**只用 `rand7()`** 实现 `rand10()`：均匀随机地返回 `[1, 10]` 的整数。

两个硬要求：

1. **期望调用次数尽量少**（不能写死次数硬试）；
2. **能证明均匀性** —— 每个 1..10 的输出概率严格是 1/10。

## 思路

- **一次 `rand7()` 无解**：它只有 7 个状态，7 不能均分成 10 份 —— 加减、取模（`rand7() % 10`、`rand7() * 10 / 7`）都不均匀。出路只有一条：**造一个更大的、能被 10 整除的状态空间**。
- **乘积空间**：两次**独立**的 `rand7()` 构成二元组 `(a, b)`，共 `7 × 7 = 49` 种组合、每种概率都是 `1/49`；拍平成一维 `v = (a - 1) × 7 + b` 就均匀取 `1..49`（`- 1` 是为了让 `a` 从 0 起，否则乘积空间有空洞）。
- **切整块**：49 里能被 10 整除的最大块是 `40 = 4 × 10` —— `v ≤ 40` 接受并输出 `(v - 1) % 10 + 1`，`v ≥ 41` 的 9 个状态整组重掷。每个输出恰好 4 个来源状态，这就是均匀性的全部来源。
- **重掷不破坏均匀性**：`P(O = k | A) = (4/49) / (40/49) = 1/10`；第 m 轮才接受时几何级数求和仍得 `1/10` —— 每一步重掷与之前独立同分布，拒绝只消耗次数、不改变条件分布。
- **期望与下界**：接受概率 `p = 40/49`，`E[轮数] = 49/40`，`E[调用数] = 2 × 1.225 = 2.45` 次；信息论下界是 `log2(10) / log2(7) ≈ 1.18` 次，差距只能靠"回收拒绝值"缩小。
- **易错点**：写成 `a * 7 + b`（得到 8..56，映射撞车）、取模写成 `v % 10`（`v = 10` 输出 0）、拒绝区间写成 `v ≥ 40`（把 40 也拒了，接受区只剩 39 个切不成 4 × 10）、拒绝后只重掷一颗骰子（破坏独立性）。

## 答案

### 解法一：拒绝采样（乘积空间 49 → 40）（时间 O(1) 期望 / 空间 O(1)）

适用场景：本题标准解 —— 利用两次采样凑出 49 个等概率状态，切出能被 10 整除的最大块 40，期望 2.45 次调用。

```python
def rand10() -> int:
    while True:
        v = (rand7() - 1) * 7 + rand7()   # 均匀取 1..49
        if v <= 40:
            return (v - 1) % 10 + 1        # 均匀取 1..10
```

### Java 版

```java
class Solution {
    public int rand10() {
        while (true) {
            int v = (rand7() - 1) * 7 + rand7();   // 1..49
            if (v <= 40) {
                return (v - 1) % 10 + 1;           // 1..10
            }
        }
    }
}
```
